Política de privacidad

DAWASSI Clipper es una herramienta personal que recorta fragmentos de directos (streams) propios o autorizados, les añade subtítulos y los publica en las cuentas sociales del propio usuario (TikTok, Telegram y, opcionalmente, YouTube).

Qué datos se tratan

  • Tokens de autorización de las cuentas conectadas (TikTok, Telegram, YouTube). Se guardan únicamente en el ordenador del usuario, en archivos locales excluidos del control de versiones. No se envían a terceros.
  • Vídeos y audio del directo que el usuario decide procesar. Se guardan en el disco del usuario y se envían a la API de TikTok solo cuando el usuario autoriza la publicación.
  • Metadatos de la publicación: título, descripción y etiquetas que el usuario configura. No se recopilan datos de espectadores.

Qué no se hace

  • No se recopilan datos personales de terceros.
  • No se venden ni se comparten datos con anunciantes.
  • No se almacenan contraseñas: la autenticación se realiza mediante OAuth de TikTok.

Conservación y borrado

Los tokens y los vídeos permanecen en el ordenador del usuario hasta que este los borra. El usuario puede revocar el acceso en cualquier momento desde Configuración → Seguridad de su cuenta de TikTok, o eliminando el archivo local de credenciales.

Términos de servicio

  1. Uso personal. La aplicación la utiliza su titular para publicar contenido propio en sus propias cuentas. No se ofrece como servicio a terceros.
  2. Contenido. El usuario es responsable de tener los derechos sobre el material que publica y de cumplir las normas de la comunidad de TikTok.
  3. Sin garantías. El software se proporciona «tal cual», sin garantía de disponibilidad ni de resultados.
  4. Límites de la plataforma. La publicación está sujeta a las cuotas y políticas de la API de TikTok; la aplicación no puede garantizar que un vídeo se publique.
  5. Cambios. Estos términos pueden actualizarse; la fecha de arriba indica la última versión.
